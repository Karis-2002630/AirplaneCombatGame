# Air battle

Air battle is a Unity project featuring aircraft flight and combat gameplay. The project includes scripts for fighter-jet control, enemy aircraft, missiles, a minimap, and flight HUD elements.

## Requirements

- Unity **6000.6.7f1**

## Open the project

1. In Unity Hub, choose **Add** and select this project folder.
2. Open it with Unity 6000.6.7f1. Unity will restore the packages listed in `Packages/manifest.json`.
3. Open `Assets/Scenes/TerrainDemoScene.unity` if it is not already open.
4. Press **Play** in the Unity Editor to run the scene.

## Project structure

- `Assets/` — scenes, scripts, models, and other game assets
- `Packages/` — Unity package manifest and lock file
- `ProjectSettings/` — Unity project and editor settings

Keep Unity `.meta` files with their corresponding assets; they preserve asset identifiers used by scenes and other project data.

## Version control

This repository is configured for a Unity project. Commit the `Assets/`, `Packages/`, and `ProjectSettings/` directories along with this README and `.gitignore`. Generated Unity data and local editor settings are excluded.
